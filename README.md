## Roadmap
We plan to evolve Newtype beyond the browser. Key goals include:

- Native app distribution
  - Add the ability to build and provide downloadable native desktop apps (outside the browser) for Windows, macOS, and Linux.
  - Evaluate frameworks such as Tauri or Electron for packaging, with a preference for lightweight, secure options.

- Rust migration
  - Gradually migrate performance-sensitive parts of the codebase to Rust to improve speed, safety, and maintainability.
  - Explore using Rust for backend components and (where appropriate) WebAssembly (WASM) for high-performance browser modules.
